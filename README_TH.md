## 📥 เริ่มต้นอย่างรวดเร็ว

### 🚀 ขั้นตอนการติดตั้ง

```bash
# ขั้นตอนที่ 1: ดาวน์โหลด
📥 รับ All-in-Craft.mcaddon จาก releases

# ขั้นตอนที่ 2: ติดตั้ง
📂 เปิดไฟล์ด้วย Minecraft

# ขั้นตอนที่ 3: เปิดใช้งาน
✅ เปิดใช้งานใน Behavior & Resource Packs

# ขั้นตอนที่ 4: เล่น
🎉 เข้าร่วมโลกและเพลิดเพลิน!
```

### 🎛️ ตัวเลือกการกำหนดค่า

<div align="center">
<table>
<tr>
<td width="50%">

#### 📦 **การตั้งค่า ItemStacker**
- 🔛 **สวิตช์**: เปิด/ปิดการรวม
- 📏 **ระยะการมองเห็น**: 1-100 บล็อก
- 🎨 **รูปแบบการแสดงผล**: การจัดสไตล์ข้อความแบบกำหนดเอง
- ⏰ **การแสดงตัวจับเวลา**: แสดงการนับถอยหลังการหายไป
- 🎯 **ตัวกรองไอเท็ม**: เลือกไอเท็มที่รวมได้

</td>
<td width="50%">

#### 🐾 **การตั้งค่า MobStacker**
- 🔛 **สวิตช์**: เปิด/ปิดการรวมมอบ
- 💀 **โหมดการตาย**: ฆ่าทั้งหมด/ทีละตัว
- 📐 **รัศมีการรวม**: ระยะ 1-20 บล็อก
- 🎭 **สไตล์การแสดงผล**: การจัดรูปแบบชื่อแบบกำหนดเอง
- 🎯 **ตัวกรองมอบ**: เลือกมอบที่รวมได้

</td>
</tr>
</table>
